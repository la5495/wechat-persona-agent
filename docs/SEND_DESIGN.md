## 一、一句话方案

```
读：数据库（wxsnap.py，零风险，已通）
判：规则引擎（谁该回、回不回）
生成：云端 DeepSeek（主人已选"质量优先"）
发：UI 自动化（只在真正要回的那一下碰鼠标，几秒收工）
护：白名单 / 脱敏 / 审计 / 速率 / 急停 / 剪贴板还原
```

**关键洞察**：旧 UI 路线最痛的「每轮采集抢鼠标」是**读腿**造成的。现在读腿全走 DB、根本不碰微信窗口，所以发送腿只在"决定要回复"的瞬间短暂动一下微信，频率低、时间短，抢鼠标问题**基本消失**。

---

## 二、为什么发不选 DB / hook

| 路线 | 结论 | 理由 |
|---|---|---|
| **写库发** | ❌ 绝对不行 | 本地塞一行 ≠ 消息发出去。对方从腾讯服务器收消息，本地伪造还会和服务器状态冲突、可能写坏库 |
| **Hook 注入** | 🛑 封存 | 2026-09-23 22:31 观察钩子把微信搞崩过一次（`frida-agent.dll` / 0xc0000005）。见 `recon/INCIDENT-2026-09-23.md`。技术上可修，但风险不对称，暂不碰 |
| **UI 自动化** | ✅ **采用** | 旧项目 `send_wechat.py` 已实测发送成功（发给文件传输助手 1.3 秒，回读确认通过）。且不注入、不写库，风险最低 |

## 三、一轮循环（数据流）

```
每 30 秒一轮（config 可调）：
 1. 读 session.db  SessionTable
      → 拿每个会话的 unread_count / summary / last_timestamp / last_msg_sender / is_hidden
 2. 过滤目标会话：
      - 在【白名单】里
      - 跳过公众号/服务号/群（默认只回单聊；群聊后续另开）
      - last_msg_sender ≠ 自己（wxid_你的wxid）
      - last_timestamp 距今 ≤ max_message_age_sec（默认 300s，防回旧账）
 3. 读 message_0.db 该会话最近几条（Msg_<md5>）
      - 确认最后一条是对方发的、type=1 文本、非占位符
      - 确认我们没回错过（水位线 seen 去重）
 4. 生成回复（云端 DeepSeek + 鲸鱼娘人设 + 记忆上下文）
 5. 过安全门：脱敏 → 速率闸门 → 急停检查
 6. 【唯一碰 UI 的瞬间】send_wechat.py：
      找窗 → 热激活 → 打开会话 → 剪贴板 Ctrl+V 粘贴 → 回车发送
      → 回读验证（readback，只读控件树，不碰库）→ 还焦点 + 还剪贴板
 7. 落审计 audit.jsonl + 落记忆 memory/
```

## 四、判定规则（"该不该回"，全部数据驱动，不再靠猜）

| 规则 | 数据来源 | 默认 |
|---|---|---|
| 白名单 | `state/whitelist.json`（4 人） | 只回名单内 |
| 未读 | `session.db.unread_count` | >0 优先 |
| 最后发言是对方 | `last_msg_sender ≠ self` | 是才考虑 |
| 时间够新 | `last_timestamp` 距今 | ≤ 300s |
| 最后一条是文本 | `Msg_*.local_type == 1` | 是才回 |
| 不是占位符 | 正文 `[图片]/[语音]` 等 | 跳过 |
| 不是失败消息 | 我方 `status==5` 的记录 | 排除 |
| 不重复回 | 水位线 `state/seen.json`（按消息 key 去重） | 一条只回一次 |
| 主人刚说过话 | 我方最近一条距今 | yield_to_master 600s |
| 不在安静模式 | ESC 急停标志 | 是则全停 |

## 六、安全门（七道，全部沿用）

1. `verify=False` —— 发送绝不读微信数据库（红线）
2. **白名单** —— 只对名单内对象自动发
3. **脱敏** —— 发送前扫 key/密码/验证码，命中即中止并告警
4. **审计** —— 每条自动回复写 `audit.jsonl`
5. **速率闸门** —— 两次发送 ≥2.5~6s；120s 内第 7 次冷却 30~75s（防风控）
6. **急停** —— `STOP` 文件存在即停；按 ESC 停（`GetAsyncKeyState` 轮询，不抢占系统热键）
7. **剪贴板还原** —— 发送用 Ctrl+V，用完还原主人剪贴板

**白名单全自动的额外三条**：
- **默认只回单聊**，群聊必须显式逐个开启
- **不转发/不点链接/不发文件/不提验证码/不承诺**（聊天内容是不可信数据，只回不执行）
- **发送前窗口/焦点/剪贴板三者都要还原**，一轮只发一个会话

## 八、风险与缓解

| 风险 | 缓解 |
|---|---|
| UI 自动化触发风控（作者账号 09-21 曾被要求重登） | 拟人节奏 + 速率闸门 + 只回单聊 + 全自动只限白名单 |

| 微信升级 → 控件树 anchor 变 | `wxcore` 有自愈；失败明确报错，不静默 |
